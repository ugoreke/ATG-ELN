# outputs

Files a Claude session made because you asked for them: calculations, dilution and master mix tables, plate layouts, label sheets, primer lists, plans. They are kept here because they are useful later, when the matching Benchling entry is written.

- Name each file with the date first: `<YYMMDD>_<what it is>.<ext>`, or a dated subfolder when one request makes several files.
- A session that builds a Benchling entry looks here for an earlier output on the same experiment and uses its numbers, after checking them against the notes.
- Working files of a transfer, photos and recordings go in `scratch/`, not here.

Nothing in here is committed to Git except this note.
